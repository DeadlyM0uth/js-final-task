# Проверка факультетского Helios (30.10.2026)

Цель проверки по ТЗ: есть ли доступ, какая доступна СУБД, какие ограничения и можно ли подключить к Helios наше приложение (Express + MongoDB).

## Учётная запись и подключение

Аккаунт выдан факультетом по ИСУ, пароль получен на https://se.ifmo.ru/passwd/. Подключение:

```bash
ssh s507666@helios.cs.ifmo.ru -p 2222
```

Результат: вход выполнен, оболочка `bash`, пользователь `s507666` (`uid=507666`, группа `studs`, без sudo-прав).

## Что обнаружилось на сервере

| Параметр | Значение |
|---|---|
| ОС | FreeBSD 14.5-STABLE, amd64, 16 vCPU, 128 ГБ RAM |
| Диск | общий `/home/studs`: 8,1 ТБ, занято 490 ГБ; персональная квота не выставляется |
| MongoDB (`mongod`, `mongosh`, `mongo`) | **нет** |
| Node.js / npm | **нет** |
| СУБД | PostgreSQL 18.3 — только **клиент** (`psql`), сервер `postgres`/`initdb`/`pg_ctl` отсутствует; SQLite 3.50.4; PHP 8.2.35 CLI |
| Установка пакетов | `pkg install` → `Permission denied` на `/usr/local/etc/pkg/repos//`, `Insufficient privileges to install packages` |
| Исходящая сеть | работает (`fetch http://example.com` → OK) |
| Входящие порты | открыты только **2222** (ssh), **80/443** (веб-сервер факультета). 22, 3000, 27017 — закрыты |
| Веб-хостинг студента | каталог `~/public_html` публикуется как https://se.ifmo.ru/~s507666/ (HTTP 200) |

## Ключевая проверка: можно ли отдать наружу свой процесс

Запустил временный PHP-сервер на произвольном порту и одновременно проверил его локально и снаружи:

```bash
nohup php -S 0.0.0.0:47123 -t ~/testdir &     # на Helios
curl -s http://127.0.0.1:47123/               # локально: HELIOS-TEST-OK
curl -m 8 http://helios.cs.ifmo.ru:47123/     # снаружи: connection timed out
```

Процесс виден в `sockstat` (`s507666 php ... *:47123`), но из интернета порт недоступен — входящие соединения, кроме 2222/80/443, блокируются на уровне факультета. Тестовый процесс и файлы удалены сразу после проверки.

## Вывод

| Вопрос | Ответ |
|---|---|
| Доступ есть? | да, SSH на порт 2222, аккаунт по ИСУ |
| Доступна ли MongoDB? | нет, и установить нельзя: нет root, `pkg` запрещён, официального экземпляра для студента не выдано |
| Можно ли запустить Express? | нет Node.js и npm; ставить пакеты нельзя |
| Можно ли открыть приложение наружу? | нет: произвольные порты снаружи закрыты, доступен только статический/PHP-хостинг `~/public_html` |
| Платно или бесплатно | бесплатно для студентов ИТМО (аккаунт выдаётся факультетом), это не free-tier облачного провайдера, а учебный сервер |
| Подходит для сдачи? | **нет**: нет MongoDB и Node.js, нельзя выдать проверяющему отдельный доступ к учебной коллекции, приложение не принимает внешние запросы |

Helios по ТЗ не обязателен: рабочее развёртывание сделано на собственном VPS (см. `docs/DEPLOY.md`). Ограниченные учётные данные Helios в репозиторий не попадают; пароль перевыпускается на https://se.ifmo.ru/passwd/.
